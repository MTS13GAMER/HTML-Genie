# 💡 HTML Genius

**HTML Genius** é um gerador visual de código HTML projetado para transformar qualquer pessoa em um mestre da web. Com uma interface intuitiva e recursos inteligentes, você constrói páginas HTML de forma rápida, prática e sem complicações — mesmo sem saber programar.

Ideal para estudantes, designers, educadores e desenvolvedores que desejam prototipar ou aprender HTML de forma visual, o HTML Genius oferece uma experiência fluida e poderosa.
